📸 Gerador de Screenshots PWA

📋 Sobre Screenshots PWA:

Os screenshots são imagens que aparecem nas lojas de aplicativos (Google Play Store, Apple App Store) quando o PWA é instalado. Eles ajudam os usuários a entender o que o app faz antes de instalá-lo.

📐 Tamanhos Necessários:
  • Wide (Desktop/Tablet): 1280x720 pixels
  • Narrow (Mobile): 750x1334 pixels (iPhone) ou 1080x1920 pixels (Android)
📝 Como Criar Screenshots:
  1. Abra o site em uma nova aba usando o botão acima
  2. Para screenshot wide (1280x720):
    • Redimensione a janela do navegador para 1280x720 pixels
    • Navegue até a página inicial (lista de ensaios)
    • Use uma extensão de captura de tela ou pressione F12 → Console → Execute: html2canvas(document.body).then(canvas => { const link = document.createElement('a'); link.download = 'screenshot-wide.png'; link.href = canvas.toDataURL(); link.click(); })
  3. Para screenshot narrow (750x1334):
    • Abra as ferramentas de desenvolvedor (F12)
    • Ative o modo de dispositivo móvel (ícone de celular)
    • Configure para iPhone 12/13 (375x812) ou similar
    • Navegue até a página inicial
    • Use a mesma técnica de captura acima
  4. Salve os arquivos como:
    • screenshot-wide.png na pasta client/public/
    • screenshot-narrow.png na pasta client/public/
  5. Recompile o frontend: npm run build

💡 Dica: Você também pode usar ferramentas online como ScreenCapture.com ou extensões do navegador para capturar screenshots.
